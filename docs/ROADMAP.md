## เฟส 3 — AI
จุดเชื่อม: `web/src/lib/ai/index.ts` (`ListingReviewer`) ถูกเรียกหลังเจ้าของส่งรายการ ผลเก็บใน `listings.ai_review` และแสดงในหน้าแอดมินแล้ว (ฟิลด์ `summary`) เมื่อต่อ API จริงเพียงเพิ่ม provider และตั้ง `AI_PROVIDER` / `AI_API_KEY`

แนวทางที่วางไว้:
1. **ตรวจรายการ** — ส่งรูป + พื้นที่ + จำนวนช่องที่แจ้ง ให้โมเดลประเมินว่าสมเหตุสมผลไหม (เช่น 20 ตร.ม. จอดรถยนต์ได้กี่คัน), ตรวจรูปไม่ตรงกับที่จอด/รูปซ้ำ แล้วให้แอดมินเป็นคนตัดสินใจสุดท้าย
2. **แนะนำที่จอดใกล้จุดหมาย** — ใช้ `ST_DWithin` ที่มี GiST index แล้ว
3. **แนะนำราคา/ทำนายความต้องการ** — ใช้ข้อมูลใน `bookings`
4. **แชตบอท** ตอบคำถามผู้ใช้

ข้อควรระวัง: เรียก AI เป็น best-effort เสมอ (ล้มเหลวแล้วไม่บล็อกการส่งรายการ — ทำไว้แล้วใน `POST /api/listings`) และอย่าให้ AI อนุมัติเองโดยไม่มีคนตรวจ
